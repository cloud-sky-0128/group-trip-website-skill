# 團體旅遊網站 Skill

這是一份可重複使用的操作配方，給支援 `SKILL.md` 的 AI 代理使用，例如 Cursor，或其他能讀取 `SKILL.md` 的代理。代理會依照這份配方，規劃、建立並免費架設一個大家一起用的團體旅遊網站。

## 這份配方是什麼

當同學或朋友要一起出遊，需要一個不用登入、手機優先、大家都能打開並一起編輯的共享網站時，代理就照這份 skill 進行：先釐清目的地、日期與要做的功能，再建立網站，最後免費託管在一個固定網址上。

## 預設功能

- 每日行程分頁
- 自由活動揪團
- 投票（任何人可新增投票與選項）
- 分帳
- 票券、地圖、天氣

## 安裝方式

把 `group-trip-website` 資料夾複製到代理的 skills 目錄。以 Cursor 為例：

```text
.cursor/skills/group-trip-website/
```

複製完成後，資料夾裡應有 `SKILL.md`。之後只要你要求規劃團體旅遊網站，代理就會讀取這份配方。
